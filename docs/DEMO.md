# Демо SmartCity (≈5 минут) и план защиты

Подготовка: `make up` (или `make dev`), открыть http://localhost:3000, дождаться, что карта района EXPO
отрисовалась (здания в 3D), а в «О данных» видны дата снимка и число мест. Ответ ИИ на CPU занимает
1–2 минуты — во время ожидания рассказывать про пайплайн (прогресс и кнопка «Отменить» видны).

## Сценарий 1 — «Я возле Mega Silk Way, 40 минут, хочу прогуляться»
1. В поле «Найти место в нашей базе» ввести «Mega» → выбрать Mega Silk Way (точка из БД, не GPS).
2. Текст: «Я возле Mega Silk Way, есть 40 минут, хочу немного прогуляться». Время 40 мин, «Вернуться сюда» включено.
3. «Подобрать прогулку». Показать: 1–3 карточки с номерами, такие же номера на маркерах; клик по карточке → карта
   летит к месту; у каждой карточки дорога туда / визит / обратно / запас / итого ≤ 40; «по прямой, время
   приблизительное»; статус часов («Часы не указаны», если в OSM нет opening_hours); источник OSM и дата.
4. Переключить 3D → 2D и обратно, «На север», «Показать результаты».

## Сценарий 2 — «Нужны кофе, тишина и розетка, есть час»
1. Текст: «Нужны кофе, тишина и розетка обязательно, есть час», 60 мин.
2. Результат: честное «подходящих мест не нашлось» — в снимке OSM ни у одного места нет подтверждённых
   розеток (power_supply). Тишина в OSM не проверяется (только пожелание).
3. Нажать предложенное ослабление «Показать варианты, где розетка не подтверждена» → кафе с пометкой
   «Наличие розеток не подтверждено» рядом с рекомендацией.

## Сценарий 3 — «Час с ребёнком, надо вернуться сюда»
1. «Демо-точка: Alem.ai, район EXPO» (подписано «Это не ваше местоположение»).
2. Текст: «Хотим погулять час с ребёнком, надо вернуться сюда», 60 мин, «Вернуться сюда» включено.
3. Результат: детские площадки (leisure=playground; безымянные показаны как «Детская площадка · без названия в OSM»)
   и/или парки; признак «для детей» подтверждён тегом; обратный путь включён в бюджет каждой альтернативы.
4. Быстрые уточнения: «Поближе», «Без кафе», «Только внутри» — жёсткие условия сохраняются.

## Отказоустойчивость (по желанию)
- Остановить Ollama (`docker compose stop ollama`) → новый запрос даёт плашку «ИИ временно недоступен — показаны
  найденные места без объяснений ИИ» (режим retrieval_only), а не шаблон под видом RAG. `docker compose start ollama`.
- Запретить геолокацию в браузере → форма работает, точка выбирается кликом/поиском.

## План защиты (слайды)
1. Проблема: «есть 40 минут — куда пойти рядом?» без выдуманных фактов.
2. Данные: ограниченный снимок OSM (Overpass), 127 мест, 1812 контуров зданий, provenance-manifest, ODbL.
3. Карта: MapLibre на собственных GeoJSON-слоях, 3D-высоты с происхождением (height / этажность / условные 10 м).
4. RAG: геофильтр → жёсткие условия → BM25 + bge-m3 (pgvector) → RRF → бюджет и часы (Asia/Almaty) →
   qwen2.5:3b генерирует только объяснения по кандидатам → сервер валидирует ID/утверждения и подставляет факты.
5. Честность: unknown ≠ yes, unknown hours ≠ open, «по прямой/примерно», no_match + ослабления.
6. Качество: тесты (unit/integration/E2E), live-smoke на настоящих данных и модели, 20 размеченных запросов.
7. Ограничения: CPU-генерация 1–2 мин, нет маршрутизатора, малое покрытие, слабые тексты 3B-модели.
8. Дальше: Valhalla для пешеходных маршрутов, векторные тайлы, расширение покрытия, GPU/hosted модель.
