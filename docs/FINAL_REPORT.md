# SmartCity — итоговый отчёт

Дата: 2026-10-18 (UTC). Ветка: `claude/wizardly-bardeen-py0dnc`. Статус по docs/ACCEPTANCE.md — в конце документа.

## Что сделано
Веб-помощник прогулок по Астане (район EXPO / MEGA Silk Way и соседние кварталы, полигон
[71.390, 51.075]–[71.445, 51.115]):

- **Карта.** MapLibre GL на собственных GeoJSON-слоях из OSM: 1812 контуров зданий (12 с внутренними кольцами), 5329 дорог,
  20 водных объектов, 1784 зелёные зоны, граница покрытия. 3D-высоты с происхождением: 23 из `height`, 897 по этажности
  (×3.2 м), 892 условно 10 м — помечены в легенде как приблизительные. 2D/3D, наклон/поворот, «на север», fit к результатам,
  выбор точки, маркеры с теми же номерами и `place_id`, что карточки. Без WebGL — SVG-карта тех же геоданных и список.
  Атрибуция © OpenStreetMap contributors. Внешних тайлов и ключей нет.
- **Данные.** Повторяемый CLI `smartcity-ingest` (Overpass read-only, группы запросов, паузы, backoff, User-Agent,
  `--retry-failed`, снимки с sha256): естественный ключ `osm/type/id`, транзакционный импорт, слияние node/way
  дубликатов (MEGA), деактивация только после полного снимка, evidence по каждому признаку, manifest и quality report.
  Чистый прогон: снимок `osm-20261018T223058Z` complete, 126 активных мест (кафе 22, еда 25, парки 5, культура 3,
  достопримечательности 4, детские площадки 66 — безымянные с подписью «без названия в OSM», ТРЦ 1), часы у 29.
- **RAG.** validate → детерминированный разбор русского текста (жёсткие условия только из явных маркеров и UI) → геофильтр →
  жёсткие фильтры → BM25 + semantic (bge-m3 через pgvector, точный скан) → RRF + дистанция + предпочтения → бюджет и часы
  (`opening-hours-py`, Asia/Almaty, весь визит, PH/SH и «10:00+» → неизвестно) → qwen2.5:3b получает только поля
  кандидатов под алиасами C1..Cn → строгая JSON-схема, известные ID, отсечение неподтверждённых утверждений →
  сервер подставляет все факты из БД. Отказ/занятость/невалидный ответ модели → честный режим «ИИ временно недоступен».
- **Бюджет.** Каждая из 1–3 карточек — отдельная альтернатива: дорога туда + визит + обратно (если «Вернуться сюда») +
  запас max(5 мин, ⌈10%⌉ дороги) ≤ бюджета. Расстояние «по прямой» ×1.3 при 4 км/ч, время помечено как приблизительное,
  маршрут не рисуется (роутер не подключён).
- **UI.** Next.js: панель «Куда пойдём?» (точка: клик / поиск по базе / демо-точка / геолокация только по кнопке),
  текст до 2000, интересы, время 10–180, возврат, обязательные условия, время старта; прогресс и «Отменить»;
  карточки с фактами и оценками раздельно, неизвестные признаки рядом; no_match с кнопками ослабления; уточнения
  «Поближе / Без кафе / Только внутри / Другие варианты»; «О данных» (покрытие, дата, источник, провайдер ИИ);
  мобильная выдвижная панель «Карта / Список»; клавиатура, axe, reduced motion.
- **Эксплуатация.** Docker Compose (db PostGIS+pgvector, api, web, ollama-профиль, healthcheck-порядок), Makefile
  (`doctor, bootstrap, models, ingest, index, dev, up, down, verify, smoke-live, eval, backup, restore, backup-test`),
  CI, секрет-скан, OpenAPI-снимок, документы приватности/лицензий/развёртывания/безопасности/демо.

## Запуск (одна последовательность)
```bash
make doctor && make bootstrap
CONFIRM=1 make models          # ~3.1 GB: qwen2.5:3b + bge-m3 (за TLS-прокси: OLLAMA_EXTRA_CA_BUNDLE=/path/ca.crt)
make ingest                    # exit 3 = partial (публичный Overpass отвечает 504) → make ingest ARGS="--retry-failed <snapshot>"
make index
make up                        # http://localhost:3000
```

## Реальные ограничения (P2/P3)
- **Скорость ИИ.** Локальная генерация на 4 vCPU без GPU — 25–90 с на ответ; при перегрузке или невалидном ответе
  модели запрос честно деградирует в «ИИ временно недоступен» (в финальном live-прогоне так случилось с 1 из 3 генераций
  API-сценариев). Генерация последовательная (`AI_MAX_CONCURRENCY=1`), параллельные запросы получают `llm_busy`.
- **Качество текстов 3B-модели** слабое: общие фразы, иногда нелогичные (самоопровержения теперь отсекаются).
  Факты от этого не зависят — их подставляет сервер.
- **Лицензия модели.** qwen2.5:3b — Qwen Research License (некоммерческое использование). Для коммерции — другая модель
  через `AI_MODEL` или OpenAI-compatible endpoint (адаптер есть, в этой среде не проверен: нет endpoint).
- **Нет пешеходного роутинга** (Valhalla — optional, не подключён): расстояния по прямой, время ориентировочное.
- **Покрытие малое**, именованных мест 60; больше половины базы — безымянные детские площадки; признаков в OSM мало
  (розетки 0, Wi-Fi 8, доступность 1) → многие жёсткие условия честно дают no_match.
- **Overpass** (публичный maps.mail.ru) часто отвечает 504 → ingest завершается partial, нужен `--retry-failed`.
  overpass-api.de из этой среды недоступен.
- **Сфера EXPO** в OSM называется «Alem.ai» (museum=future) — не попала в POI-категории; высота по умолчанию 10 м.
- **maplibre-gl 5.24.0**: advisory DOM.sanitize (fix в 6.x) — недостижим в нашем коде, принят как риск R1 (docs/SECURITY.md);
  миграция на 6.x требует отдельной работы (проверено: карта не инициализируется).
- Парсер — правила для русского: редкие формулировки («нужна детская площадка обязательно», «без фастфуда» = вся еда)
  трактуются неточно; LLM жёсткие условия не добавляет.
- Прямой порт API (127.0.0.1:8000) доверяет X-Forwarded-For: локальный процесс на том же хосте может обойти rate limit.
- Firefox/WebKit не запускались (не установлены). Live T10/T12/T18/T21 проверены только детерминированно.
- Публикация не выполнялась; `client_request_id` не даёт серверной идемпотентности.

## Опциональная конфигурация
`AI_PROVIDER=openai_compatible` + `AI_BASE_URL`/`AI_API_KEY` (секрет только в env; UI предупреждает о передаче текста
внешнему провайдеру), аналогично `EMBEDDING_*` (смена модели → `make index`). `ROUTING_PROVIDER=valhalla` — не реализован
сверх структурированного `routing_unavailable`. `API_DOCS=1` — интерактивная документация API.

## Демо (3 сценария, подробно — docs/DEMO.md)
1. **«Я возле Mega Silk Way, 40 минут, хочу прогуляться»**: точка из поиска «Mega» → 1–3 места (например, NU Park:
   12 + 11 + 12 + 5 = 40 мин), номера на карточках и карте совпадают, «Часы не указаны», источник OSM.
2. **«Нужны кофе, тишина и розетка обязательно, есть час»**: честное «не нашлось» — розетки в OSM не подтверждены ни у
   одного места; кнопка ослабления → кафе с пометкой «Наличие розеток не подтверждено»; тишина — только пожелание.
3. **«Хотим погулять час с ребёнком, надо вернуться сюда»**: демо-точка EXPO → детские площадки (признак «для детей»
   подтверждён тегом), обратный путь в бюджете каждой карточки; «Поближе / Без кафе / Только внутри» сохраняют условия.
