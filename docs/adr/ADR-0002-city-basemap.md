# ADR-0002: базовая карта всей Астаны, крыши и спутниковый гибрид

Дата: 2026-10-19. Статус: принято (решения владельца продукта от 2026-10-19).

## Контекст
Карта показывала только GeoJSON-слои района EXPO (2,7 МБ, серые объёмы). Нужна карта всего города с загрузкой по
видимой области, отделённая от ограниченной базы рекомендаций, и заметно более реалистичный 3D без платных сервисов.

## Проверка текстурированных 3D-данных (2026-10-19)
Бесплатных легальных фототекстур фасадов Астаны не найдено: Google Photorealistic 3D Tiles — ключ и биллинг (покрытие
Астаны публично не подтверждено, условия против смешения с не-Google картами), Cesium ion / 2GIS / MapTiler / Mapbox /
Esri World Imagery — аккаунт, ключ или подписка. Без разрешения ничего не подключалось (docs/SOURCES.md п. 12).

## Решение
1. Векторные тайлы в PMTiles, отдаваемые API `/api/tiles/{base,buildings}/{z}/{x}/{y}`:
   - `base` — вырезка ежедневной сборки Protomaps (`pmtiles extract`, bbox 71.15–71.85 E, 50.83–51.38 N, z0–15, ≈10 МБ);
   - `buildings` — собственные тайлы зданий (z13–15, ≈4 МБ) из выгрузки Geofabrik: источник высоты, цвета, крыши.
   bbox проверяется по административной границе OSM relation 3087155 (793,6 км²): `boundary_inside_tiles=true`.
   Первая вырезка (до 50.93 N) границу не покрывала — исправлено. Граница рисуется на карте и в «О данных».
2. Высоты (изменение SPEC §5 с разрешения владельца): height → levels×3,2 → оценка по типу/площади (`estimate`) →
   условные 10 м. Частные дома и гаражи больше не получают автоматически 10 м.
3. Крыши: ступенчатое приближение только по тегу roof:shape (линейный профиль — скатные, четверть окружности — купола,
   эллипсоид — orb/sphere). Кураторская стилизация Нур Алема (`config/landmark_shapes.json`): сфера диаметром контура
   с верхом на высоте OSM на узкой опоре, применяется только после проверок (id, округлость ≥ 0,95 в метрах, внутри
   way/454857501 с museum=future, смещение ≤ 30 м); подписана «стилизация».
4. Подложка «Гибрид» по умолчанию: EOxCloudless 2024 (10 м/пикс) на обзоре, схема на уровне улиц; «Схема» — в
   переключателе. Спутник «C» отдельно не делается: на близком масштабе он размыт. Спутник разрешён только при явно
   заданном `APP_USAGE_MODE=noncommercial` (CC BY-NC-SA 4.0); по умолчанию (`commercial`, fail-closed) API его не
   отдаёт, браузер не обращается к EOX. В демо (`.env`) режим некоммерческий: при первом открытии карты браузер
   запрашивает обзорные снимки у tiles.maps.eox.at (IP и видимые тайлы видны EOX) — раскрыто в «О данных» и PRIVACY.

## Последствия
- `make basemap` (≈2–3 мин, ≈240 МБ скачивания в `data/cache`, кэшируется); без архивов `/api/ready` показывает
  компонент `basemap: unavailable`, но не блокирует готовность; UI показывает «Базовая карта города недоступна».
- Независимое ревью (2026-10-19) учтено: геометрии только Polygon/MultiPolygon, fail-closed лицензия, версия тайлов в
  URL, слабый ETag для gzip, атомарная запись манифеста/границы, оценки по площади не применяются к building:part.
- Фотореалистичных фасадов нет: здания — стилизованные объёмы; это прямо сказано в легенде и «О данных».
- Сборки Protomaps хранятся ограниченное время: в манифесте записан ключ сборки и sha256 результата.
