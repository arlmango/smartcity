# Приватность SmartCity

## Что обрабатывается
| Данные | Где | Хранение |
|---|---|---|
| Исходная точка (lat/lon) | браузер → API → (LLM не получает координаты пользователя) | только в рамках запроса; в логах округление до 0.01° (~1 км) |
| Текст запроса и уточнения | браузер → API → LLM-провайдер | не пишется в логи и БД; диалог хранится только в памяти вкладки |
| Геолокация браузера | только по нажатию «Моё местоположение», после пояснения | не сохраняется; отказ не мешает работе |
| Ответ (рекомендации) | API → браузер | не кэшируется между пользователями (`Cache-Control: no-store`) |

## AI-провайдер
- По умолчанию локальный Ollama: текст запроса не покидает машину/контур развёртывания.
- При `AI_PROVIDER=openai_compatible` текст запроса и данные мест-кандидатов (без координат пользователя) отправляются на указанный оператором endpoint. Интерфейс показывает провайдера в блоке «О данных». Оператор отвечает за договор с провайдером.
- Пользовательские запросы не используются для обучения.

## Логи и retention
- Логи API: request_id, путь, статус, длительности этапов, число кандидатов, ID выбранных мест, округлённая точка. Без сырого текста, без секретов.
- Логи контейнеров ротируются Docker (по умолчанию json-file); рекомендуемый retention для деплоя — 14 дней (docs/deployment.md).
- Артефакты live-smoke (artifacts/live) содержат тестовые запросы сценариев S1–S3 (не персональные) и округлённые координаты.

## Секреты
Только переменные окружения (`.env` не коммитится). Серверные ключи не передаются в браузер. `make verify` запускает scripts/secret_scan.py.
