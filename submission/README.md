# SmartCity — пакет сдачи

SmartCity подбирает короткую прогулку по Астане. Пользователь выбирает точку старта и пишет, чего хочется. Сервис
возвращает 1–3 реальных места из собственной базы OpenStreetMap: с объяснением, временем дороги и посещения и пометками,
что не подтверждено. Под капотом семантический поиск по embeddings плюс геофильтр, а локальная языковая модель
объясняет только найденные места. Названия и координаты всегда берутся из базы, а не из ответа модели.

## Что нужно
- Docker Desktop (на Linux — Docker Engine с Compose), Git, [uv](https://docs.astral.sh/uv/), make.
- 8 ГБ RAM (комфортно 16 ГБ), 10–15 ГБ свободного диска, интернет для первой установки.
- Windows — только через WSL2 с Ubuntu (подробно в `docs/LOCAL_RUN.md`).

## Запуск (команды из `docs/LOCAL_RUN.md`)
```bash
git clone -b claude/wizardly-bardeen-py0dnc https://github.com/arlmango/smartcity.git
cd smartcity
make bootstrap                 # .env из .env.example, зависимости Python, база данных
CONFIRM=1 make models          # локальные модели ИИ: ~3,1 ГБ (qwen2.5:3b и bge-m3)
make ingest ARGS="--from-snapshot osm-20261018T200514Z"   # данные OSM из снимка в репозитории, без интернета
make basemap                   # тайлы карты всей Астаны: ~240 МБ загрузки, 2–3 мин
make index                     # смысловой индекс мест
make up                        # запуск; затем http://localhost:3000
```
Готовность: `curl http://localhost:8000/api/ready` — у db, data, map, embeddings, llm должно быть `ok`.
Остановка: `make down` (данные и модели сохраняются).

## Три демо-сценария
1. **Кофе и прогулка рядом.** Нажмите «Демо-точку» (район EXPO) или кликните по карте внутри зелёной пунктирной зоны.
   Напишите «Хочу выпить кофе и немного погулять», выберите 40 минут, нажмите «Подобрать прогулку». Появятся 1–3
   карточки с теми же номерами, что на карте. Клик по маркеру открывает карточку, клик по карточке перелетает к месту.
2. **С возвращением и временем.** «Час с ребёнком, вернуться сюда». В бюджете учтены дорога туда, посещение, обратный
   путь и запас. Где детские условия не подтверждены источником, это сказано прямо.
3. **Честный отказ.** «Кофе с розеткой, 1 час». Наличие розеток в данных не подтверждено, поэтому сервис честно говорит,
   что подходящих мест нет, и предлагает ослабить условие. Ещё: клик вне зелёной зоны — «Вне зоны рекомендаций».

## Известные ограничения
- **Рекомендации только в районе EXPO / MEGA Silk Way** (126 мест). Карта показывает всю Астану, но база мест собрана
  только в этой зоне.
- **Карта стилизованная.** Здания — объёмы по контурам OSM, без фасадных текстур. Высоты частично оценочные: их
  источник показан в легенде, оценки светлее. Крыши приближены по тегу `roof:shape`. Нур Алем — упрощённая
  стилизация.
- **Расстояния по прямой, время приблизительное. Уличной маршрутизации нет**, линии маршрута на карте не строятся.
- Ответ ИИ на обычном процессоре — 30–90 с; найденные места видны раньше объяснений.
- По умолчанию (`APP_USAGE_MODE=commercial`) только схема. Спутниковый слой EOX доступен только при
  `APP_USAGE_MODE=noncommercial` и только после согласия пользователя.
- Проверено в Chromium и WebKit. Firefox не запускался: его блокирует песочница среды разработки. На реальных слабых
  телефонах производительность не измерялась.

## Что в архиве исходников
ZIP — это **исходный код** для установки по командам выше, а не автономная готовая сборка.
- **Включено:** код (web, API, ingest), конфиги, Docker-файлы, тесты, документация, снимок данных OSM
  `data/snapshots/osm-20261018T200514Z`, слои карты района `data/map/*.geojson`, манифест и граница города
  `data/basemap/manifest.json`, `astana-boundary.geojson`.
- **Не включено:** `.env` и любые секреты (создаются из `.env.example`), `node_modules` и `.venv` (ставит
  `make bootstrap`), модели ИИ (~3,1 ГБ — `make models`), тайлы карты `*.pmtiles` (~14 МБ — `make basemap`),
  кэши и тяжёлые артефакты проверок: скриншоты и логи `artifacts/clean-install`, `artifacts/live`,
  `artifacts/map-redesign`, `artifacts/screenshots`. Они остаются в репозитории.
