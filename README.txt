SmartCity: пакет постановки задачи для Claude Code

Начни с START_HERE.txt. В архиве не готовое приложение, а полный набор требований для его реализации.

Состав:
START_HERE.txt — инструкция пользователю и основной промпт.
RESUME_PROMPT.txt — продолжение после лимита/остановки.
CLAUDE.md — правила работы внутри проекта.
SPEC.md — продуктовые и функциональные требования.
.claude/agents/ — пять готовых ролей custom subagents.
docs/ARCHITECTURE.md — стек, компоненты, schema/API и реальные AI providers.
docs/ACCEPTANCE.md — критерии готовности, тесты и проверки.
docs/DESIGN.md — визуальная система и UI.
docs/OPERATIONS.md — этапы, скрипты, запуск, отчёты, ограничения.
docs/SOURCES.md — официальные источники.
STATUS.md, NEXT_STEPS.md, docs/VERIFICATION.md — исходное честное состояние NOT_STARTED.
design/ — 3D-референс с происхождением геометрии и оценками высот.
MANIFEST.sha256 — контрольные суммы файлов пакета.

Для нового repo распаковать в корень. Для существующего не перезаписывать пользовательские инструкции: сохранить в отдельной папке и попросить объединить. Облачное хранилище без доступа Claude Code к рабочим файлам само по себе не запускает работу.

Важное: лимиты Claude/облачной среды остаются. Для настоящего RAG нужна реально доступная модель (локально или через разрешённый endpoint). Проект не должен прикидываться готовым, если обязательная интеграция не проверена. Маршрутизация по улицам и публичное размещение не входят в безусловную обязательную готовность; их статусы всегда явные.
